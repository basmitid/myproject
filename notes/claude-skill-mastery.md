## Part 1. 개념 — Skill이란 무엇인가

### 1-1. 정의 [18:45]
| 항목 | 내용 |
|---|---|
| ⭐ 정의 | 일하는 방법을 **글과 자료로 묶은 폴더** |
| 동작 | Claude가 폴더를 꺼내 안의 내용을 **그대로 수행** |
| 비유 | 직원에게 건네는 **업무 안내서(Manual)** [22:30] |

### 1-2. 구조 [24:25]
```
📁 my-skill/
 ├─ 상단 2줄  ← 이름 + 설명 (AI가 "이 Skill을 쓸지" 판단하는 근거)
 └─ 본문      ← 업무 순서 · 기준 · 규칙 · 예외 처리
```
- 실행 여부는 **상단 2줄만으로** 결정 → 이름·설명은 반드시 명확하게

### 1-3. 작동 원리 [21:38]
1. AI가 모든 Skill의 **이름·설명(상단 2줄)만** 먼저 읽어 둔다
2. 명령이 들어오면 "아, 이 일이구나" 하고 해당 Skill을 인식
3. 그 Skill의 **본문 지침을 전부 수행**

> ⭐ **Context Window 절약** [24:25] — 필요한 Skill의 본문만 읽으므로 불필요한 정보가 처리되지 않아 성능 저하가 최소화된다.

## Part 2. 비교 — Prompt vs Skill

| 구분 | Prompt [28:16~29:16] | Skill [29:16~30:56] |
|---|---|---|
| 호출 | 매번 찾아서 복사·붙여넣기 | ⭐ **한 줄 명령**으로 자동 호출 [30:56] |
| 보관 | 여러 곳에 흩어짐 | Skill 라이브러리로 한곳에 |
| 반복 사용 | 전체 내용을 매번 재입력 | 이름만 부르면 끝 |
| 조합 | 수동으로 이어 붙임 | 여러 Skill을 AI가 **자동 조합** |
| Context | 전부 읽어 낭비 | 필요한 것만 읽어 효율적 |
| 개선 | 원본 프롬프트를 직접 고침 | ⭐ "이렇게 고쳐줘" → **Skill 문서 자체 수정** [28:16] |

**AI의 Skill 추론 능력** [30:56]
- Skill이 쌓이면 AI가 필요한 것을 골라 조합
- "이 사람은 이렇게 일하는구나"를 학습해 **나의 기준과 절차**를 자동 적용

## Part 3. 실전 — Skill 사용의 3가지 방식

> ⭐ 오늘 배울 3가지 [34:51]

| # | 방식 | 핵심 | 난이도 |
|---|---|---|---|
| ① | **기본 Skill 사용** | Anthropic(Claude)·OpenAI 기본 제공 | ★☆☆ |
| ② | **남의 Skill 받아 쓰기** | 신뢰할 수 있는 사람의 Skill 업로드 | ★★☆ |
| ③ | **직접 Skill 만들기** | 내 반복 업무를 Skill로 정의 | ★★★ |

### ① 기본 Skill 사용 [34:51~39:42]
- 지원 문서: **PowerPoint · Word · Excel · PDF · HWP(한글)**
- Adobe·MS Office 라이선스 없이 작업 가능, 별도 설치·다운로드 불필요

**실습 예시 — PDF** [35:47~38:47]
```
명령: "PDF 여러 개를 하나로 합쳐줘. 비밀번호 걸어줘"
결과: 병합 + 암호 설정된 파일이 즉시 생성 ⭐ [37:48]
```
- 의의: 유료 SW 비용 절감 · 외부 도구 검색/설치 불필요

### ② 남의 Skill 받아 쓰기 [47:23~49:18]

**설치 절차**
1. 신뢰할 수 있는 사람(예: 강사)에게 Skill **zip 파일** 받기
2. Claude → **설정(Settings) → 기능(Features) → Skill**
3. **"추가" → "Skill 업로드"**
4. zip 파일 선택 → 업로드 완료

**사용법** [49:18]
- 채팅에서 관련 명령만 하면 자동 실행
- 예: "진단해줘" → 강사의 진단 Skill이 실행되어 글을 진단

> ⚠️ 보안은 [Part 5](#part-5-관리--skill-품질과-보안) 참고

### ③ 직접 Skill 만들기 [54:34~55:29]

**언제 만드나?**
- ⭐ 같은 요청을 반복하고 있다면 → **"이거 Skill감이구나"** [54:34]
- 예: 매주 카페 글 읽기 → 정리 → 형광펜 → 편집

**4단계 정의법**

| 단계 | 할 일 | 위치 |
|---|---|---|
| Step 1 | 부를 때의 **명령어/이름** 정하기 | 상단 2줄 |
| Step 2 | **일의 순서** 정의 | 본문 |
| Step 3 | **작업 기준·규칙** 정하기 | 본문 |
| Step 4 | **불확실할 때의 처리** 정하기 | 본문 |

> ⭐ Step 4 필수 문구: **"모르겠으면 할루시네이션 하지 말고 나한테 꼭 물어봐"** [54:34]

**개선 사이클** [28:16]
```
실행 → 결과 확인 → "이건 별로, 이렇게 해줘" → Skill 문서 수정 → 재실행
```
- 최종 산출물도 변경 가능 (예: "최종 대본을 줄게" ↔ "카드 뉴스를 줄게")

## Part 4. 사례 — 반복 업무를 Skill로 바꾼 예

### 사례 A. 성과 카드 뉴스 Skill [27:02~28:16]
- **목적**: 카페 성과 글 중 뉴스 가치 있는 내용 선별 → 인스타형 카드 뉴스 제작
- **명령**: `"성과 카드 뉴스 만들어줘"`

| 단계 | 내부 절차 |
|---|---|
| 수집 | 1. 글 후보 고르기 → 2. 내용 읽기 |
| 선별 | 3. "부럽다/대단하다" 싶은 내용 선택 → 4. 표로 정리 |
| 제작 | 5. 말풍선 작성 → 6. 근거 문장·사진 연결 → 7. 카드 디자인 |
| 마무리 | 8. 검수 → 9. 결과 보고 → 10. 강사에게 전달 |

### 사례 B. 영수증 처리 Skill [56:49~60:14]

| Before | After |
|---|---|
| 영수증을 매번 수동 정리 → 엑셀 입력 | **사진만 찍으면** 끝 |

```
📷 사진 → OCR로 읽기 → 날짜·금액·가게명 추출 → 엑셀 자동 입력 → 세무사에게 이메일
```
> ⭐ 사용자의 역할은 **사진 찍기 하나** [60:14]

### 사례 C. 글 진단 Skill [45:30~64:47]
- **목표**: 강사의 기준으로 글 진단 + 개선안 제시

| 기존 (6번 왕복) | Skill (1번) |
|---|---|
| 잘한 점 → 잘못한 점 → 고칠 방법 → 요약 → 3가지 안 → 재작성 | ⭐ **한 번에 전 과정 실행** [45:30] |

**진단 결과 예시 — 투빈맘님 글** [46:28~63:46]

| 구분 | 내용 |
|---|---|
| 👍 좋은 점 | 학생들 말투가 자연스러움 |
| 👎 문제점 | 타깃 불명확 (초1? 초3? 나이 미기재) |
| | 광고처럼 보임 ("YES24 한정판 미니노트 키링") |
| | 채널 약속 미충족 (엄마가 공부하는 모습 없음) |
| | 출판사 문장을 그대로 인용 |
| ✍️ 개선안 1 | **내 말투대로** — 우리 집 장면 추가, 행동 요청 하나로 |
| ✍️ 개선안 2 | **더 친밀하게** — 대화체로 |
| ✍️ 개선안 3 | **더 믿음 가게** — 공식적·정중한 톤으로 |

## Part 7. 마인드셋 — 강사의 학습·성장 전략

### 7-1. 도메인 + AI [87:52~89:40]
- ⭐ AI를 전공으로 삼지 말고 **기존 전공에 AI를 붙여라** [88:44]
- 강사의 도메인: 콘텐츠 · 수익화 · 심리학 · 마케팅
- "AI 전문가" < **"콘텐츠 + AI 전문가"**

### 7-2. 계속 학습 [85:18~87:52]
- ⭐ AI는 변화가 너무 빨라 배운 것이 금방 구식이 됨
- 혼자보다 **우수한 사람들과 함께(집단지성)**
- 학습법: 학습 노트(Artifact) · 자료 노트 · 대시보드로 공부 프로세스 체계화

### 7-3. 실용 팁
| 주제 | 조언 |
|---|---|
| 말투 학습 [75:42] | ⭐ 글보다 **음성 녹음**으로 학습 → Whisper로 텍스트 변환 → AI가 말버릇 파악 [76:41] |
| AI 슬럼프 [84:24~91:33] | 정상적인 현상. 도메인 전문성 우선, AI는 보조. 서로 주고받는 "선순환 공동체" |
| 투자 관점 [92:26~93:23] | 고급 정보 = 힘 = 돈. 투자 → 성장 → 수익 → 재투자 |

### 7-4. 최종 목표 [60:14]
> ⭐ **"한 마디만 하면 나머지는 AI가 해준다"**
>
> 반복 업무를 **일의 순서**로 정의 → AI가 수행 → 나는 최소 입력만
>
> Skill 습득 = **시간 절약 + 비용 절감 + 정확도 향상**

## 부록. 나만의 Skill 작성 템플릿

강의의 4단계 정의법(Part 3-③)을 그대로 옮긴 양식입니다. 복사해서 채워 쓰세요.

```markdown
---
name: receipt-to-excel
description: 영수증 사진을 받으면 날짜·금액·가게명을 추출해 엑셀에 정리하고 세무사에게 보낼 때 사용
---

# 영수증 정리 Skill

## 1. 일의 순서
1. 첨부된 영수증 이미지를 읽는다 (OCR)
2. 날짜, 금액, 가게명을 추출한다
3. 지정된 엑셀 파일에 한 행씩 추가한다
4. 세무사에게 보낼 이메일 초안을 만든다

## 2. 작업 기준
- 날짜 형식: YYYY-MM-DD
- 금액: 원 단위, 쉼표 없이 숫자만
- 가게명: 영수증 상단 표기 그대로

## 3. 불확실할 때
- 글자가 흐리거나 판단이 어려우면 **추측하지 말고 반드시 나에게 물어본다**

## 4. 결과 보고
- 추가된 행 수와 확인이 필요한 항목을 요약해서 알려준다
```

**작성 체크포인트**
- `description`(상단 2줄)에 **언제 써야 하는지**가 분명한가? → AI가 이것만 보고 판단
- 순서·기준이 다른 사람이 읽어도 그대로 따라 할 수 있을 만큼 구체적인가?
- "모르면 물어봐" 규칙이 들어 있는가?
